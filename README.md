# دانشیار — Daneshyar

پلتفرم آموزشی تحلیلی مبتنی بر مدل یادگیری (SLM) برای پایه‌های دهم تا دوازدهم، بر پایه ۶ سند مرجع موجود در همین مخزن.

## معماری کلی (طبق اسناد: Modular Monolith)

```
frontend/  →  Next.js 14 (PWA-ready, RTL فارسی, Tailwind)
backend/   →  FastAPI + SQLAlchemy async
             ├─ Phase 0: ساختار سازمانی Province→District→School→Class + User→Employee→Employment→SchoolAssignment
             ├─ RBAC: Role + Permission + Scope + Assignment + Delegation + AuditLog (قاعده طلایی در بک‌اند)
             ├─ Catalog: Book→Chapter→Topic→Skill + گراف پیش‌نیاز + دوره‌های ۱۴ روزه
             ├─ SLM: فرمول‌های خالص M/R/S/E + شواهد وزن‌دار + تاریخچه + دفترچه خطا (۶ علت)
             ├─ Assessment: بانک سؤال با کج‌فهمی/علت گزینه‌های غلط، بلوپرینت، Snapshot سازمانی
             ├─ Teacher: رادار مباحث کلاس + ریشه‌یابی گراف پیش‌نیاز + گروه‌بندی ۵گانه نیاز
             ├─ School: مقایسه کلاس‌ها + سامانه «نیازمند بررسی» + تشخیص چندعاملی + نمایه معلمان
             └─ Employment: گردش کار درخواست + جدول سیاست + تأیید ناحیه
             ├─ Remediation: آزمون هدف‌محور از خطاهای باز + چرخه بازآزمون (resolve/relapse)
             ├─ Parent/Boards: پیوند والد-فرزند + بردهای نام‌مستعار با حداقل جمعیت ۱۰
             ├─ Assistant: نرمال‌سازی فارسی + کش معنایی + بازیابی منابع + مسیریابی مدل (small/large)
             ├─ Stats: تجمیع national/province topic_stats با قاعده حریم خصوصی
             └─ Tutoring: بازار معلم خصوصی + چت گروهی + فیلتر ایمنی زیر ۱۸
```

## اجرای سریع (بدون Docker)

```bash
# ۱) بک‌اند
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # ویندوز
# یا: source .venv/bin/activate && pip install -r requirements.txt
.venv/Scripts/python -m scripts.seed                      # ساخت DB نمونه
.venv/Scripts/python -m uvicorn app.main:app --port 8000  # اجرای API
```

```bash
# ۲) فرانت
cd frontend
npm install
npm run dev      # http://localhost:3000
```

## اصول پیاده‌شده از اسناد

- **دو شاخص جدا:** پیشرفت در برنامه ≠ تسلط واقعی؛ شکاف > ۱۵ → پیام «خوانده اما جا نیفتاده»
- **عکس لحظه‌ای سازمانی** روی هر پاسخ آزمون (school/class/teacher/district/province)
- **۶ علت خطا** با نگاشت گزینه‌های غلط → علت (کج‌فهمی‌محور طراحی سؤال)
- **قاعده طلایی RBAC** در بک‌اند: «هیچ‌کس بیشتر از دسترسی خودش تفویض نمی‌کند» + لاگ ممیزی
- **جدول سیاست استخدام** (نه منطق سخت‌کدشده) — رسمی/دولتی → خودکار، قراردادی → تأیید ناحیه
- **کف فراموشی ۴۰٪:** `E = M × (0.6 + 0.4×R)` و حداقل ۳ شاهد برای وضعیت
- همه پارامترها در `Settings` قابل تنظیم (نه هاردکد) — آماده کالیبراسیون پایلوت

## داشبورد مدیر مدرسه (سند مدیر مدرسه §3–§8)

سه تب در `/admin` (با دسترسی `view_school_analytics`):

1. **مقایسه کلاس‌های یک درس:** تسلط/ماندگاری/خطا هر کلاس + اختلاف با میانگین هم‌درس‌ها. پرچم «کلاس دارای افت» وقتی فعال می‌شود که اختلاف ≥ ۱۰ واحد باشد (`DROP_VS_PEERS_UNITS=10`) و حداقل ۳ دانش‌آموز (`MIN_GROUP_FOR_COMPARISON=3`) — «پرچم است، نه حکم».
2. **نیازمند بررسی:** ۴ نوع پرچم (خطای تکراری باز، افت نسبت به هم‌گروه‌ها، نرخ مشارکت کم، عدم ثبت فعالیت پلتفرم) با توضیح و اقدام پیشنهادی؛ هر پرچم دکمه میان‌بر تشخیص دارد.
3. **نمایه معلمان:** فقط شاخص‌های عینی (کلاس، تعداد دانش‌آموز، تسلط، ماندگاری، تعداد خطا) — **بدون امتیاز عددی کلی**؛ قضاوت نهایی به بررسی زمان‌بندی‌دار.

**تشخیص چندعاملی هر کلاس:** غالب‌ترین علت خطا + دانش‌آموزان بدون شواهد کافی + مباحث نیازمند ریشه‌یابی — ورودی بررسی مدیریتی، نه ارزیابی تدریس.

2. ✅ **هسته معلم:** رادار مباحث کلاس، ریشه‌یابی گراف پیش‌نیاز، گروه‌بندی ۵گانه نیاز

4. ✅ **آزمون هدف‌محور + گردش کار ترمیم/بازآزمون** (`/student/errors` + سرویس `remediation`): خطا باز → بازآزمون از همان مباحث → resolve با نسبت ≥ `RETEST_PASS_RATIO` وگرنه relapse
5. ✅ **پنل والدین + بردها** (مدرسه/استان/کشور) با نام مستعار و حداقل جمعیت ۱۰ (`/parent`, `/boards`)
6. ✅ **دستیار هوشمند** (`/assistant`): نرمال‌سازی فارسی + کش معنایی (Jaccard) + بازیابی سبک روی کاتالوگ + مسیریابی small/large + منابع روی هر پاسخ (جدول Evidence با منبع ai_chat در `Settings.assistant_evidence_weight` آماده اتصال است)
7. ✅ **مدیر استان/وزارت** (`/geo`): تجمیع‌های `national_topic_stats` با بازمحاسبه، مجوزهای جدا (`view_province_analytics` / `view_national_analytics`)
8. ✅ **معلم خصوصی** (`/tutor`): بازار + درخواست جلسه + چت گروهی با فیلتر شماره تماس/پیوند خارجی + دکمه گزارش + لاگ ممیزی
9. ✅ **اصلاحیه‌های سند RBAC**: دسترسی موقت با انقضای خودکار (`permission_expired`)، اعمال Scope در `require_permission`، قاعده تفویض Scope-محور با پاسخ 403، جدول سیاست استخدام قابل ویرایش، معاون با چک‌لیست مجوز پویا (§6)، انتقال معلم و بستن assignment قبلی بدون تغییر تاریخچه (§10)
10. ✅ **پنل مدیر ناحیه** (`/district`): داشبورد ناحیه، ثبت/فعال‌سازی مدرسه، تعیین و تغییر مدیر مدرسه، تعریف کارکنان ناحیه، کارتابل استخدام فیلترشده
11. ✅ **صلاحیت معلم** (درخواست کارفرما): به‌ازای هر (معلم، درس، سال) دو آزمون — سنجش دانش درس + سنجش مهارت مدیریت کلاس؛ نمره‌دهی و وضعیت واجد/آزمایشی/بحرانی (`teacher_pass_score` / `teacher_critical_score`)؛ دید ناحیه + اقدام اصلاحی (دوره/نظارت/تعویض) با لاگ ممیزی
12. ✅ **بینش تحلیلی استان/وزارت** (`/geo/national/insights`, `/geo/province/{id}/insights`): بدترین درس‌ها/مباحث، رتبه‌بندی استان‌ها با رعایت سرکوب حداقل جمعیت، توصیه‌های اولویت‌دار قاعده‌محور
